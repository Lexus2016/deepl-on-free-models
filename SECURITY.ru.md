# Безопасность

[English](SECURITY.md) · [Українська](SECURITY.uk.md) · **Русский**

## Ключи и секреты

- Ключи API хранятся в **Keychain macOS**, отдельный элемент для каждого
  провайдера (`service = ua.admin.hymt`, `account = provider:<id>`). Новые
  элементы используют класс защиты `kSecAttrAccessibleAfterFirstUnlock`.
- Ключи никогда не записываются в `UserDefaults`, историю переводов, логи или
  файлы репозитория.
- В репозитории нет `.env`-файлов, токенов, приватных ключей или моделей.
  `.gitignore` исключает `.env`, `*.key`, `*.pem`, `*.gguf`, `build/`, `.build/`
  и логи.
- Если ключ попал в коммит или публичный репозиторий, немедленно отзовите его в
  панели провайдера. Считайте историю git скомпрометированной: ключ нужно
  считать публичным, даже если коммит позже удалён.

## Приватность

- Локальные провайдеры (Ollama, LM Studio, oMLX, llama.cpp) не отправляют текст
  по сети.
- Облачные провайдеры (Ollama Cloud, OpenRouter, Groq, Cerebras) получают
  переводимый текст на своих условиях и по собственной политике данных.
- У приложения нет телеметрии, аналитики или фонового соединения с серверами
  авторов.
- Разрешение **Accessibility** используется только для отправки `⌘C` активному
  приложению перед переводом выделенного текста. Приложение не читает события
  клавиатуры и не собирает содержимое других окон.
- История переводов хранится локально в
  `~/Library/Application Support/DeepL-oFM/history.json` и очищается на вкладке
  «История». Отключите **«Сохранять историю переводов»**, чтобы прекратить
  запись.

## Сообщение об уязвимости

Не создавайте публичный issue с деталями эксплуатации. Используйте GitHub
**Security → Report a vulnerability** (приватная консультация) в этом
репозитории.

Укажите:

- версию/коммит;
- версию macOS и способ запуска (локальная сборка или `/Applications`);
- шаги воспроизведения;
- ожидаемое и фактическое поведение;
- затрагивает ли проблема ключи API или данные пользователя.

Ответ — в течение 7 дней. Пожалуйста, не публикуйте детали до выпуска
исправления.
