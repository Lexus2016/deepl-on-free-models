# Безпека

[English](SECURITY.md) · **Українська** · [Русский](SECURITY.ru.md)

## Ключі та секрети

- Ключі API зберігаються в **Keychain macOS**, окремий елемент для кожного
  провайдера (`service = ua.admin.hymt`, `account = provider:<id>`). Нові
  елементи використовують клас захисту `kSecAttrAccessibleAfterFirstUnlock`.
- Ключі ніколи не записуються в `UserDefaults`, історію перекладів, логи або
  файли репозиторію.
- У репозиторії немає `.env`-файлів, токенів, приватних ключів чи моделей.
  `.gitignore` виключає `.env`, `*.key`, `*.pem`, `*.gguf`, `build/`, `.build/`
  і логи.
- Якщо ключ потрапив у коміт або публічний репозиторій, негайно відкличте його
  в панелі провайдера. Вважайте історію git скомпрометованою: ключ треба
  вважати публічним, навіть якщо коміт пізніше видалено.

## Приватність

- Локальні провайдери (Ollama, LM Studio, oMLX, llama.cpp) не надсилають текст
  у мережу.
- Хмарні провайдери (Ollama Cloud, OpenRouter, Groq, Cerebras) отримують текст,
  який перекладається, на своїх умовах і за власною політикою даних.
- Застосунок не має телеметрії, аналітики чи фонового з'єднання із серверами
  авторів.
- Дозвіл **Accessibility** використовується лише для надсилання `⌘C` активному
  застосунку перед перекладом виділеного тексту. Застосунок не читає події
  клавіатури й не збирає вміст інших вікон.
- Історія перекладів зберігається локально в
  `~/Library/Application Support/DeepL-oFM/history.json` і очищується на
  вкладці «Історія». Вимкніть **«Зберігати історію перекладів»**, щоб припинити
  запис.

## Повідомлення про вразливість

Не створюйте публічний issue з деталями експлуатації. Використайте GitHub
**Security → Report a vulnerability** (приватна консультація) у цьому
репозиторії.

Додайте:

- версію/коміт;
- версію macOS і спосіб запуску (локальна збірка чи `/Applications`);
- кроки відтворення;
- очікувану й фактичну поведінку;
- чи зачіпає проблема ключі API або дані користувача.

Відповідь — протягом 7 днів. Будь ласка, не публікуйте деталі до випуску
виправлення.
